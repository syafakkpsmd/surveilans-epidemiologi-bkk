# Input data klinik binaan (ICV/e-ICV) dan akses per klinik

- Tabel: `schema/mariadb/08_klinik_akses.sql` (`klinik_akses`, serta kolom `no_dokumen`, `sumber`, `batch_id` di `data_icv` dan `sumber`, `batch_id` di `stok_vaksin`).
- Akses (`lib/klinik/akses.ts`): admin dan petugas melihat/mengisi semua klinik; **petugas_klinik hanya klinik yang ditautkan admin** (Admin → Verifikasi Akun → "Atur klinik"). Tanpa tautan = tidak ada data (gagal tertutup). Penyaringan di server: dashboard klinik, stok vaksin, `/api/klinik/{rekap,tren,search,stok/pemakaian}`.
- `/api/klinik/search` (data pribadi peserta) kini WAJIB login; sebelumnya terbuka untuk siapa pun.
- Input: `/dashboard/klinik/input` (form + unggah Excel + daftar), API `/api/klinik/icv/*`. Judul kolom = sheet lama; Jenis Vaksin 1-3 dan Komorbid (tombol Tambah, maksimal 6) mengikuti dropdown sheet.
- Baris dari aplikasi disimpan dengan `spreadsheet_id = app-<id klinik>` dan `sumber` 'input'/'upload', terpisah dari baris sinkronisasi Sheets (yang tidak pernah menyentuhnya). Dashboard membaca keduanya. Nomor dokumen yang sudah ada dilewati saat unggah (tidak menimpa).
- Tanggal diproses `lib/tanggal/parse-tanggal.ts` (bersama). Kolom Excel bercampur gaya hari/bulan dan bulan/hari ditolak; teks ambigu dibaca hari/bulan dan diberi peringatan.
- Dashboard komorbid kini membaca semua `Komorbid N`, mengenali Hipertiroid dan Riwayat Tumor, dan menghitung penyakit di luar daftar sebagai "Lainnya".
- Stok: halaman yang sama (`/dashboard/klinik/input?bagian=stok`), SATU form dengan dropdown jenis (e-ICV, ICV, Meningitis MM, Yellow Fever, Polio, Influenza), unggah Excel, dan riwayat. Stok = buku besar per (klinik, jenis): petugas mengisi Stok Masuk, Terbit, Rusak; **Sisa dihitung otomatis** (sisa kemarin + masuk − terbit − rusak), dihitung ulang bila ada input mundur/hapus, dan isian yang membuat sisa negatif ditolak. Stok awal = "Stok Masuk" di tanggal mulai. Satu baris per tanggal per jenis (isian di tanggal yang ada menawarkan ganti). Judul tab Sheets lama dikenali di unggahan (Stok Pelayanan, E-ICV Terbit, Vaksin Terbit/Rusak); kolom Sisa diabaikan.
- Dashboard stok: per (klinik, jenis) dipakai SATU sumber, yang tanggalnya paling baru (sama = aplikasi), supaya klinik yang beralih dari Sheets ke aplikasi tidak dihitung ganda (`getSumberAktifStok`). Rata-rata pemakaian harian dihitung per hari yang tercatat; hari tanpa catatan tidak dihitung (estimasi hari habis sedikit lebih pendek).
- Uji: `NODE_OPTIONS="--conditions=react-server" npx tsx --test --test-force-exit scripts/migrate/uji-klinik-icv.ts` (butuh MariaDB berisi schema 01, 02, 05, 08); stok: `uji-klinik-stok.ts` (cara sama).
